# Anatomical heart model attribution

CARDIAC//BREACH loads its anatomical heart model at runtime from the open-source **Human-Organ3D** project:

- Repository: https://github.com/yihalem123/Human-Organ3D
- Model: `models/heart.glb`
- Source README describes the heart as a realistic GLB with chambers/vessels and heartbeat animation.

The application does **not** claim that the model file itself has the same license as the repository code. Verify the model-file licensing terms before redistributing the binary or bundling it into a commercial release. The current game keeps the model externally referenced and retains this attribution notice.
