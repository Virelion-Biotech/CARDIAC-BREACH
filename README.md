# CARDIAC//BREACH

A browser-based cardiac tissue strategy simulator.

## Play

Open `index.html` locally, or enable GitHub Pages for the repository. No build system or dependencies are required.

## Core loop

1. Choose a tissue challenge.
2. Inspect the virtual cardiac tissue.
3. Deploy up to three autonomous response agents.
4. Advance the simulation one day at a time.
5. Balance viability, function, inflammation, fibrosis, and energy.
6. Finish a 20-day run and receive a score.

## Included scenarios

- Ischemic injury
- Inflammatory cascade
- Progressive fibrosis
- Maturation failure
- Electrical instability

## Agents

- Stabilizer
- Regenerator
- Immune Modulator
- Vascular Support
- Maturation Agent
- Custom agents

This is an educational game/simulation. Its tissue model is intentionally abstract and does not provide real-world biological intervention instructions.
